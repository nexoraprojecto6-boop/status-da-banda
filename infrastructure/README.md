# infrastructure/
- `environments/` — configuração por ambiente (dev/staging/prod), sem segredos.
- `database/` — esquemas, migrações, seeds de dados geográficos.
- `deployment/` — pipelines CI/CD e scripts de deploy.
- `monitoring/` — métricas, logs, alertas.
- `security/` — políticas, modelos de ameaça, checklists.
