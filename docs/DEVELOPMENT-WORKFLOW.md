# Fluxo de Desenvolvimento
1. Ler `AI-CONTEXT`, `DEVELOPMENT-STATE`, `NEXT-PHASE`.
2. Confirmar fase autorizada pelo dono do projeto.
3. ADR para decisões importantes antes de implementar.
4. Implementar no escopo; testar; atualizar docs/CHANGELOG.
5. Entregar ZIP/commit; aguardar aprovação antes da fase seguinte.
Branches: `phase/NN-nome` → PR → `main`. Unity: Force Text serialization, Visible Meta Files, Git LFS para binários. Revisões: checklist (segurança, performance, compatibilidade).
