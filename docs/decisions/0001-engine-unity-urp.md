# ADR-0001: Unity 6 LTS + URP
**Estado:** Proposto. **Contexto:** jogo 3D mobile multiplayer, equipa reduzida. **Decisão:** Unity (confirmar versão LTS suportada na Fase 2) com C# e URP. **Consequências:** ecossistema maduro; dependência de licença/custos Unity; validar tamanho de build e desempenho em Android baixo. **Alternativas:** Unreal, Godot.
